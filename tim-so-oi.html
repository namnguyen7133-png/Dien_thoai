Ket Qua Tra Bang 1

Ket qua duoc sap xep tu so nho nhat den lon nhat (bao gom tat ca so lien ke)

Luu y: Ket qua hien thi cho TAT CA cac so lien ke tu so nho nhat den so lon nhat trong day so nhap vao.
So goc So tra bang 1 Ky tu dac biet
Chua co du lieu
Quy tac tra bang 1: So ≤ 12 tra thang bang, so > 12 lay so du khi chia cho 12 (neu du = 0 thi lay 12)

Ket Qua Tra Bang 2

Ket qua duoc sap xep tu so nho nhat den lon nhat (bao gom tat ca so lien ke)

Luu y: Ket qua hien thi cho TAT CA cac so lien ke tu so nho nhat den so lon nhat trong day so nhap vao.
So goc So tu Bang 1 Ky tu Bang 2 Ky tu dac biet
Chua co du lieu
Quy tac tra bang 2: Lay chu cai dau va cuoi cua so bang chu, ket hop voi ky tu dac biet tu so Bang 1 (11-15)
